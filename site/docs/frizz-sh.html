A name on frizz.sh

The shortest path, and the only one that needs nothing of your own — no domain, no port forwarding, and no extra binary to install.

  press R, choose frizz.sh name, and give it one

  Name  ada

  claiming ada.frizz.sh for GitHub user ada

Your board stays on loopback and dials out to frizz.sh. That single fact removes the inbound port, the tunnel binary and the DNS record all at once, so a laptop behind any NAT works with no configuration. The connection comes back by itself after a sleep or a network change, so a board is reachable again as soon as the machine is.

Claiming a name

Claiming requires the GitHub CLI signed in. Frizz asks gh for a token, the registrar spends it on your account id and discards it, and the name is bound to that account.

Renewals need neither. Your machine holds an Ed25519 key at ~/.frizz/identity.key, and that key alone proves ownership afterwards — so the name keeps working whether or not GitHub does. Ownership moves between machines the way an SSH key does: copy the file.

Every launch renews the lease. A name nobody has run for 30 days is released and can be claimed by someone else.

What you are agreeing to

  • One name per GitHub account. An account less than 30 days old cannot claim.
  • The name is a lease, not property. It lapses after 30 days unused, and Frizz can reclaim any name at any time — that is the only enforcement there is, so it has to exist.
  • Your traffic passes through us. A name on frizz.sh is served by a relay we run: every request and every keystroke goes through it. Frizz’s own access gate still runs on your machine, so a visitor meets it whether or not the relay is honest — but if you would rather no third party carried the bytes, use a domain you control.
  • No warranty. This is a free convenience on a domain someone else owns. Anything you cannot afford to lose access to belongs on a domain you control.

Opening it elsewhere

The launch prints a single-use link as a QR code. Scan it and the code is spent — the phone holds a session cookie from then on. For another device, mint another:

$ npx frizz --link
