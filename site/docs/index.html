Remote access

Frizz binds 127.0.0.1. To reach a board from a phone or another machine, press R in the terminal running it and pick how it should be reached.

  Reach this board from anywhere

  ❯ frizz.sh name
    Cloudflare Tunnel
    Tailscale
    Something else
    Off                 (current)

The walkthrough checks what each route needs — a signed-in GitHub CLI, cloudflared, a tailnet — before it accepts your answer, and the choice is remembered, so a plain npx frizz serves it from then on. Whichever you pick, Frizz gates it the same way and prints a single-use sign-in link — as a QR code, so a phone can scan it off the terminal. Press L for a fresh one, or run npx frizz --link from another shell.

Anything that gets past this gate can run shell commands as you. The gate is standing, not a formality: every request and every socket has to carry the session, so a device that has not redeemed a link is refused no matter what sits in front. What a tunnel or proxy adds is TLS and a hostname — the authentication is Frizz’s.

Pick a route

RouteNeedsReach
A name on frizz.shA GitHub accountAnywhere
Cloudflare TunnelA domain on CloudflareAnywhere
TailscaleA tailnetYour devices
SSH port forwardingSSH accessOne session
Any reverse proxyA domain and a serverAnywhere

The shortest path is a name on frizz.sh: it needs no domain, no port forwarding, and no extra binary. Everything else here works without us.

Signing a device out

Redeeming a link signs a device in for a year, so a phone you no longer have is a phone that can still reach your shell. Every device that redeemed a link is listed, and each can be signed out on its own:

$ npx frizz --sessions
  4-DY69Dr  Safari on iPhone   2d ago
  q7mJx_uZ  Chrome on macOS    just now

$ npx frizz --sign-out 4-DY69Dr
Signed out 4-DY69Dr.

--sign-out all signs out every device at once. Both run against the board already running on this machine, and both are refused unless they arrive on loopback — so a stolen session cannot sign you out and keep the board to itself. Over SSH counts as loopback, which is how a headless box is managed.

Headless machines

A machine nobody can watch cannot show a QR code. Mint a single-use code over SSH instead:

$ ssh you@your-machine 'npx frizz --link'

There is no standing secret. Access codes and the sessions they mint are the only gate, which means a leaked link expires the moment it is used rather than staying valid forever.
